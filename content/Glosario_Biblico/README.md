# Glosario bíblico para Obsidian — Zettelkasten

## Cómo instalar
Copia la carpeta `Glosario_Biblico` dentro de tu bóveda de Obsidian y abre `00 - Glosario bíblico.md`.

## Diseño
- Un término = una nota atómica.
- El nombre del archivo es el término, para facilitar enlaces `[[Término]]`.
- Cada nota tiene un `id` Zettelkasten en YAML.
- Las conexiones se escriben como wikilinks de Obsidian.
- La plantilla permite continuar agregando nuevos términos.
- El MOC funciona como puerta de entrada, no como índice rígido.

## Recomendación
No intentes completar todo el glosario de una vez. Cuando un término genere una idea independiente —por ejemplo, una discusión sobre `téktōn` y el oficio de Jesús— crea una nueva nota conceptual y enlázala desde la nota léxica.
